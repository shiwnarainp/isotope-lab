# Isotope Lab: Discovering Isotopes and Calculating Average Atomic Mass

An interactive 30–45 minute lab for 10th-grade New York State Regents Chemistry (NYSSLS HS-PS1-1). Students build isotopes, explore percent abundance, and calculate weighted average atomic mass.

**Format:** one self-contained `index.html`, no install or sign-in.

## Modules (40-minute plan)

1. **Discover isotopes (5 min):** compare carbon-12, -13, and -14 models; four investigation questions, a conclusion, and a quick check.
2. **Build and compare (7 min):** a proton/neutron/electron builder with live element, mass number, charge, and notation. Build chlorine-37 from chlorine-35, then decode ²³Na, ²⁴Mg, ²⁷Al, and ³⁷Cl, plus random extra isotopes.
3. **Percent abundance (6 min):** a 100-atom population with a slider. The average atomic mass and a number line update live; three scenarios lead to the discovery statement.
4. **Average atomic mass (10 min):** guided step-by-step calculation (10.25 amu) and chlorine (35.45 amu). Also a calculator with real data for B, C, Ne, Mg, S, Cl, and Cu that checks abundances total 100%.
5. **Isotope Detective (5 min):** five cases with hints.
6. **Mastery assessment (7 min):** 10 questions with rounding tolerance, skill mastery, recommended review, retry, and copyable or printable results.

**Class length:** the 30-minute mode trims practice items but keeps every core concept. The 45-minute mode adds the "Find the Missing Isotopic Abundance" algebra extension.

## Notes for teachers

- Particle colors are fixed: protons red (+), neutrons blue (n), electrons grey (−), with labels and a legend so color isn't the only cue.
- Real isotopic masses and abundances (IUPAC) reproduce the periodic-table values. Hypothetical element X is labeled as an instructional approximation.
- Targeted feedback covers the six listed misconceptions (for example, using the simple average, or counting electrons in mass number).
- Four proficiency levels, vocabulary tooltips, sentence starters, an on-screen calculator, reduced motion, and keyboard support.
- Progress is saved only in each student's own browser.
